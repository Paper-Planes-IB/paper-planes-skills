## Как читать реестр

### Канон

- Живая база знаний: `https://lms.paper-planes.ru/knowledge/...`.
- Источник скилла: локальный `SKILL.md` в `.codex/skills` или `.agents/skills`.
- GitHub указывается только там, где отдельный репозиторий реально найден. Сейчас подтверждён отдельный репозиторий для `frappe-lms-factory`.
- Quartz/local markdown остаётся сборочным слоем; финальной публикацией считается страница в Frappe LMS.

### Типы

| Тип | Что входит |
|---|---|
| BPM / методология | BPM, BPV, рыночные модели, dashboard-семантика, расчёты и управленческие фреймворки. |
| AI Text Editor | Инструменты снятия ИИ-звучания и редакторские правила. |
| Управление проектами | ClickUp, handoff, project passport, встречи, КП и операционные контуры. |
| Внутренние процессы | QA, LMS, vault, ingest, governance, проверки, синхронизации и инфраструктурные скиллы. |
| Контент и редактура | Статьи, посты, SEO, письма, кейсы, презентации, визуальные и редакторские скиллы. |
| Общее / без среза | Всё, что пока не попало в один из устойчивых типов. |

### Как устроена таблица

- `Скилл` ведёт на отдельную страницу с полным текстом скилла в LMS.
- `Что делает` — короткое описание из frontmatter.
- `Доп. срезы` показывает все классификации, если скилл относится сразу к нескольким контурам.
- `GitHub` заполняется только для подтверждённых репозиториев.

## Как читать реестр

### Канон

- Живая база знаний: `https://lms.paper-planes.ru/knowledge/...`.
- Источник скилла: локальный `SKILL.md` в `.codex/skills` или `.agents/skills`.
- GitHub указывается только там, где отдельный репозиторий реально найден. Сейчас подтверждён отдельный репозиторий для `frappe-lms-factory`.
- Quartz/local markdown остаётся сборочным слоем; финальной публикацией считается страница в Frappe LMS.

### Типы

| Тип | Что входит |
|---|---|
| BPM / методология | BPM, BPV, рыночные модели, dashboard-семантика, расчёты и управленческие фреймворки. |
| AI Text Editor | Инструменты снятия ИИ-звучания и редакторские правила. |
| Управление проектами | ClickUp, handoff, project passport, встречи, КП и операционные контуры. |
| Внутренние процессы | QA, LMS, vault, ingest, governance, проверки, синхронизации и инфраструктурные скиллы. |
| Контент и редактура | Статьи, посты, SEO, письма, кейсы, презентации, визуальные и редакторские скиллы. |
| Общее / без среза | Всё, что пока не попало в один из устойчивых типов. |

### Как устроена таблица

- `Скилл` ведёт на отдельную страницу с полным текстом скилла в LMS.
- `Что делает` — короткое описание из frontmatter.
- `Доп. срезы` показывает все классификации, если скилл относится сразу к нескольким контурам.
- `GitHub` заполняется только для подтверждённых репозиториев.
