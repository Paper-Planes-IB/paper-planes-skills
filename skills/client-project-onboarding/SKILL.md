# client-project-onboarding

Назначение: старт/онбординг клиентского проекта в CORD-формат (скелет + первые артефакты).

v0: создаёт checklist-файл в `Vault/60-отчёты/onboarding/<ДД-ММ-ГГГГ>-<проект>.md`.

## Коммерческое происхождение проекта

При старте нового клиентского проекта, выигрыше КП, подтверждении запуска или post-hoc заведении уже идущего проекта агент обязан собрать короткий intake-блок для P1-метрик Двойки и занести его в:

`Vault/10-отделы/02-продажи-маркетинг/04 — Коммерческие функции/Реестр коммерческого происхождения проектов.md`

Минимальный intake:

- сделка;
- клиент;
- owner сделки;
- тип отношений с клиентом: новый клиент / повторный проект / реактивация спящего клиента / расширение текущего проекта;
- дата первичного обращения;
- источник;
- конкретный материал / событие / рекомендация;
- квалификация: да / нет / сомнительно;
- ICP-класс / гипотеза;
- ICP-fit: high / medium / low / disqualified;
- отрасль;
- продукт / тема;
- продуктовая витрина: да / нет / частично; какая карточка / маршрут;
- delivery: Old Delivery / New Delivery / hybrid / Downsell;
- консультация / диагностика до проекта: да / нет; дата; формат;
- КП отправлено: да / нет, дата;
- статус: выиграно / проиграно / в работе;
- первая цена в КП / первой версии цены;
- итоговая цена / сумма договора;
- forecast snapshot: дата / сумма / вероятность / ожидаемая дата закрытия;
- скидка от первой цены: нет / %, сумма;
- ценовые уступки: нет / изменение порядка оплаты / рассрочка / постоплата / снижение предоплаты / бесплатные допработы / расширенный scope / иное;
- единицы уступки: рубли / % / дни cash-сдвига / часы или слоты / качественно;
- New Delivery / Access Fee / value-outcome logic: нет / да / частично / исключение Old Delivery;
- что повлияло на решение;
- нужен ли сигнал в 7-ку.

Intake самодополняющийся: если проектный чат создаётся из выигранного КП, сначала найти архивированное КП и routing / trace-блок коммерческого этапа, перенести известные поля в реестр, а у Ильи спросить только недостающее.

Если часть данных неизвестна, не блокировать старт проекта: заполнить известное, неизвестные поля отметить как `неизвестно`.

Запуск:

```bash
python3 scripts/client_project_onboarding_scaffold.py --project "Название проекта"
```
