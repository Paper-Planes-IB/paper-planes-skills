# autoresearch

Назначение: автономный исследовательский цикл по теме/компании/рынку, с фиксацией промежуточных артефактов в vault.

v0 (без веба): создаёт план и backlog вопросов в `Vault/60-отчёты/autoresearch/<ДД-ММ-ГГГГ>-<тема>.md`.

Запуск:

```bash
python3 scripts/autoresearch_scaffold.py --topic "Тема"
```
