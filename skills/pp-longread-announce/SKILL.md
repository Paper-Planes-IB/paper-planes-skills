# pp-longread-announce

## Назначение

Этот mirror нужен, чтобы codex-контур явно видел отдельный downstream-дистрибуционный скилл после лонгрида.

## Canonical source

Полный рабочий контракт живёт здесь:

`Vault/10-отделы/02-продажи-маркетинг/03 — Дистрибуция контента/03.1 — Собственные каналы/_скилл — pp-longread-announce/SKILL.md`

## Когда использовать

- когда лонгрид уже готов;
- когда нужен TG-анонс;
- когда нужна IG-карусель;
- когда контентный план 02.5 подставляет лонгрид в слот анонса.

## Контур взаимодействия

1. `pp-longread-leverage` или ручная редакционная работа создаёт готовый лонгрид.
2. Илья акцептует лонгрид.
3. `pp-longread-announce` собирает TG/IG пакет.
4. Материалы падают в контур `03 — Дистрибуция контента/`.

## Примечание

Mirror не копирует весь текст оригинального skill, а фиксирует его роль в codex-архитектуре.

## Writeback / Approval Gate

Этот skill считается рискованным, потому что готовит производные тексты для внешней дистрибуции в Telegram/Instagram и может исказить смысл принятого лонгрида.

Анонс можно готовить только из принятого источника. Перед публикацией, передачей наружу, изменением контент-плана, созданием/обновлением файлов дистрибуции или изменением статуса слота нужно получить акцепт Ильи. Не добавлять новые claims, которых нет в approved longread.

## Externalization / DLP Gate

Анонс не должен расширять раскрытие по сравнению с approved longread. Перед внешней публикацией проверить: нет ли новых клиентских фактов, цифр, обещаний, внутренних терминов, чувствительных деталей или claims, которых нет в принятом источнике. Если есть сомнение, убрать или вернуть на акцепт Илье.
