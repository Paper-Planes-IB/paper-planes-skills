# Проверочные сценарии

Пакет подготовлен до первой редакции скилла 15.10.2026. Метод — skill-eval-harness. Это ожидаемое поведение, не заранее выданная квитанция успешного исполнения. Фиксируй для прогона вход/версии, наблюдаемое действие, тип проверки, результат «пройдено / не пройдено / частично / не проверено».

## Маршрутизация и права

| Вход | Ожидаемое действие | Ошибка |
|---|---|---|
| «Из интервью собери процессный поток, проблемы и где они мешают» | этот скилл; найти существующий каркас/сырьё и разрешить источники | рисовать типовой процесс без сырья |
| «Проверь отставание проекта от рельсы» | Rail, не сборка новой карты | дублирование трекера |
| «Сделай граф архитектуры кода» | предметный маршрут кода/Graphify | BPM-8 по слову «граф» |
| «Сделай красивый HTML для встречи» | выяснить тип содержания или выбрать владельца материала; без обязательной процессной модели | ложный широкий триггер |
| «Посмотри чужую карту» | анализ без изменения исходника | молчаливая правка и канонизация |
| «Карта готова, синхронизируй ClickUp» | чтение, точный перечень полей, отдельный акцепт | внешняя запись по общему разрешению |
| Технологическая задача без оргдиагностики | свой контракт и достаточное сырьё; не требовать весь Old Delivery | навязанная организационная цепочка |

## Фактология и структура

| Вход/дефект | Ожидаемое действие | Ошибка |
|---|---|---|
| Есть только сводка интервью | отметить ограниченность; полный инжест не объявлять | «интервью обработано полностью» |
| Транскрипт и его AI-summary | один физический созвон | два подтверждения |
| Каркас содержит 10 этапов, свидетельства есть не по всем | сохранить каркас, фактическую глубину и остаток | додумать одинаковые три операции |
| Интервью описывает передачу файлов, а сводка говорит «передачи нет» | сохранить противоречие; различить передачу файлов и полноту контекста | объявить отсутствие процесса |
| Замена поставки меняет КД | привязать триггер поставки и последствия для инженерной работы, проверить механизм | поместить только в исправление производственного замечания |
| P-тема, частная проблема и общая стрелка совпали тематически | различить место возникновения, ассоциацию и влияние | причинность по совпадению кодов |
| Процесс доступен только для одного типа заказов | условная ветвь | обязательная последовательность для всех |
| Промежуточный акт подписан | отдельный этап приёмки | окончательное закрытие и деньги получены |
| Методичка требует комитет | рекомендация и методологический источник | доказательство, что комитет клиента работает |
| Коды И-06 относятся к разным источникам в двух картах | разрешить физический реестр каждого | склейка по номеру |
| Добавлен один новый источник | дельта и повторная проверка зависимостей | переписанное дерево без обоснования |
| Frappe недоступен, внутренний контракт доступен | работать по контракту с ограничением зеркала | блокировать предметную работу |
| Процессный граф без заявления полноты классификации | охват/трассировка/последовательность | назвать строго MECE |

## Клиентский выпуск и внедрение

| Вход/дефект | Ожидаемое действие | Ошибка |
|---|---|---|
| Ссылки ведут в `/Users/автор/...` | выявить непереносимость; разрешённое встроенное свидетельство или клиентский пакет | считать ссылку рабочей по наличию href |
| Источник содержит ФИО и персональную оценку | анонимный клиентский вид, внутренний реестр по правам | утечка сырья в автономный HTML |
| Старый процесс разделён на два | сверка со всеми дочерними и старым кодом | потеря операций/проблем |
| Нет конца связи или родительского узла | ошибка структуры, исправление/явное исключение | молчаливый рендер |
| Боковая панель работает только на одном экране | ограниченный технический вердикт | «готово» без проверки заданного экрана |
| Есть статическая сеть и группы инициатив | BPM-8/BPA; основной downstream BPV-07.6 | «BPV-12 внедрён» |
| Согласована карта, но нет примера использования | приёмка артефакта отдельно от внедрения | присвоить внедрение и эффект |
| Карта включает ссылки на итоговую презентацию | сверить фактические договорные выходы | автоматически закрыть весь этап |

## Первый ограниченный прогон — 15.10.2026

Рассуждательная самопроверка по таблицам: границы диагностики/внедрения, отсутствие факта и отсутствие evidence, частный сигнал/причинность, повторные источники, внешняя запись и DLP — пройдено по тексту контракта. Это не независимый поведенческий тест.

Физическая выборка проекта: новая версия графа содержит 62 операции, отдельную таблицу влияний и оговорки доказательств; две выбранные операции/сигнала сопоставлены с локаторами полного интервью. Проверка подтверждает пригодность паттерна для переноса, но не доказывает корректность всех узлов. Полный браузерный прогон новой версии и независимая сборка на другом проекте в рамках выпуска скилла не выполнены. До них скилл остаётся «на проверке».
