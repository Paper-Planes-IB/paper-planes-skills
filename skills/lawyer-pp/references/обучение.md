# Память решений lawyerPP

Единственный журнал состояния — `решения.json`. Он не заменяет физический договор. Поручение Ильи от 07.10.2026 разрешает постоянное сохранение его прямых договорных решений в этой библиотеке.

## Схема карточки

Обязательные поля:
- `id` — неизменяемый ID, например `LPP-014`.
- `название`, `тема`, `риск`, `решение` — конкретные русские формулировки.
- `статус` — `Принято`, `Отклонено`, `Кандидат` или `Заменено`.
- `область` — `уровень` (`Только проект`, `Шаблон для адаптации`, `Предпочтение владельца`, `Общее правило владельца`), `проект`, `юрисдикция`, `сторона`, `тип_сделки`.
- `условия_применения`, `не_переносить`, `остаточный_риск` — списки.
- `источник` — `тип` (`Прямое решение владельца` либо `Предложение агента`), `цитата`, `локатор`, `дата`, `физические_источники`. Не выдумывай message ID; достаточно даты, реплики и объекта аннотации.
- `состояние_редакции` — что внесено и что неизвестно о принятии клиентом.

Дополнительно: `редакция`, `связанные_решения`, `правовые_точки_проверки`, `история`.

Первоначальные карточки — решения по КТ Амур. `Шаблон для адаптации` означает возможность предложить механизм, не общее обязательное правило Ильи. Цены, ставки и сроки остаются `Только проект`. Не внесённые в DOCX позиции о выездах и восстановлении учёта прямо отмечены как не внесённые.

## Перенос конкретного кейса в метод проверки

Поручение «дополни скилл» разрешает обновить согласованный порядок проверки и выбора защитной конструкции в существующем SKILL.md и его ссылочных файлах. Оно не повышает автоматически статус договорных карточек: точная редакция, коммерческие числа, сроки и клиентский акцепт по-прежнему требуют своих источников. Не создавай карточку только для дублирования процедуры из SKILL.md.

Для кейса МКЗ отказ от явных цен этапов сохранён в LPP-014 как `Отклонено / Только проект`; пакет альтернативных формулировок без цен этапов — LPP-015, `Кандидат / Только проект`. Переносимый метод — при общей цене проверять самостоятельную полезность, приёмку, права использования и расчёт фактических услуг, отделённый от графика платежей. Он не отменяет прямо согласованные цены этапов другого договора и не принимает весь пакет LPP-015. После акцепта исследовательского пакета 08.10.2026 принятие механизмов качества и доказательств записано отдельно в LPP-017, выбранный общий предел неустойки 10% — LPP-018. LPP-015 сохраняет статус кандидата только для прежнего целого пакета точной редакции, включая сроки расчёта 10 + 10 рабочих дней; это не отменяет прямого принятия LPP-017 и LPP-018. При новых прямых решениях проверяй актуальные карточки; этот абзац не заменяет единственный журнал состояния `решения.json`.

## Цикл записи

1. Найди конкретное предложение и прямую реплику владельца. Не распространяй согласие на соседние альтернативы; причину отказа не придумывай.
2. Подбери карточку по механизму и области. Локальное исключение нового клиента не затирает другого клиента или общее предпочтение.
3. Сформируй JSON во временном файле. По умолчанию правка локальна; общий уровень — только по явной команде `всегда / для всех договоров`.
4. Запиши и прочитай результат:

```bash
python scripts/decisions.py record --input /absolute/temp/decision.json
python scripts/decisions.py show --id LPP-014
python scripts/decisions.py validate
```

Для пересмотра нужны уточнённый источник и основание:

```bash
python scripts/decisions.py record --input /absolute/temp/revised.json --revise --reason "Прямое уточнение владельца"
```

Скрипт проверяет структуру, сохраняет предыдущую версию и пишет атомарно. Достоверность акцепта устанавливает агент: нельзя маркировать мнение клиента как прямое решение владельца.
5. Повтори подбор изменённого риска. Новая карточка должна быть доступна следующему процессу, прежние ограничения — сохранены. Покажи ID, решение и область.

Если скрипт недоступен, допустима минимальная ручная правка JSON с временной резервной копией и проверкой чтением. Второй реестр не создавай. Закон, документ клиента и вывод агента не становятся принятыми правилами; `Кандидат` не применяется как акцепт. При противоречии закону сохраняй факт предпочтения, но не юридическую гарантию. Глобальные файлы памяти Codex, коммерческие реестры и внешние системы этот цикл не меняет.
