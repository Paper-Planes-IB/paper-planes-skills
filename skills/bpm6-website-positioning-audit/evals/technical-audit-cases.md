| Пустой `raw/browser.json` или пустой DOM | Браузерные измерения сохраняют статус «не удалось измерить»; отсутствует положительный вердикт | Файл существует — значит все браузерные проверки «пройдены» |
| Запрещённый query внутри iframe | Отказ сохраняет тип и локатор фрейма; он не выдаётся за смену главного URL | Чужой фрейм меняет атрибуцию основного документа |
| JS пытается открыть запрещённый query | До отправки блокируется целевой запрос; целевой URL и причина сохраняются отдельно от фактического URL | Попытка исчезает из отчёта, поскольку переход не состоялся |
| Sitemap сразу перечисляет страницу третьего уровня | Глубина навигации равна кратчайшему пути из стартовой страницы; sitemap — отдельный источник обнаружения | Sitemap обнуляет навигационную глубину |
| Один URL повторяется в sitemap | Уникальная очередь обхода и число исходных вхождений учитываются раздельно | Множество уникальных URL скрывает дубли sitemap |
| Совпадает текст двух страниц; третья немного отличается | Точное и близкое совпадения имеют разные определения, пары и доказательства | Эвристика близости объявлена точным дублем или обе проверки считают одну пару дважды |
| Ссылка на существующий / отсутствующий fragment | HTTP-доступность и наличие `id` / именованного якоря проверяются отдельно | HTTP 200 закрывает проверку якоря; `#` исчезает при нормализации |
| JSON-LD валиден как JSON, но неполон / расходится с HTML | Автоматически найдена адресная семантическая кандидатура с ограничением и следующей проверкой | Парсинг доказывает право на rich result или нарушение, санкцию, снятие индексации |
| Изображения и сетевые пробы превышают выборку | Число обнаруженных, измеренных, не измеренных объектов и пределы видимы; неполная выборка не «пройдена» | Измерены все изображения / ресурсы по факту нескольких проб |
| Сжатый ответ и условный запрос с 304 | Заголовки, реальные размеры передачи и результат условного запроса разделены; 304 не становится HTML-страницей | Отсутствующее тело 304 объявлено пустым контентом; заголовок подтверждает размер или скорость |
| Четыре параллельных HTTP-работника | Общий request budget, один календарь начала запросов и прежние robots / query-границы | Каждый работник получает полный лимит или собственная пауза умножает частоту запросов |
| Малое gzip-тело распаковывается в большой HTML | Сохраняется исходная передача; отдельно применяется предел распакованного ответа и статус усечения | Ограничение сжатых байтов разрешает неограниченную распаковку |
| Главная навигация не измерена / заблокирована | Нулевое число найденных переходов остаётся «не удалось измерить»; iframe / POST отдельно не лишают измеренную главную навигацию пригодности | Отсутствие наблюдённого перехода объявлено доказанным отсутствием переходов |
| `#submenu:`, `#popup:`, hash-router и реальный ID с двоеточием | Существующий ID имеет приоритет; прочие команды требуют интерфейсной проверки; обычный `#missing` остаётся якорным кандидатом | Команда автоматически объявлена отсутствующим HTML-ID или работающей функцией |
| Профилирование с полезным главным кодом, дочерним iframe и страницей ошибки | Coverage сохраняет собственный JS/CSS главного фрейма; дочерний / внутренний код исключён; неизвестный scope явно ограничивает измерение | `chrome-error` / iframe CSS или JS увеличивают объём кода основной страницы |
| В серии профилирования есть пригодный и непригодный прогоны | Пригодный результат сохранён; непригодный DOM / timeout / блокировка получает адресную строку PERF-06; оба гейта показывают eligible/all | Непригодные прогоны исчезают, поскольку другой прогон уже измерен |

Исполняемая часть: `python3 scripts/test_audit.py`; браузерные сценарии дополнительно включаются через переменные `AUDIT_NODE`, `NODE_PATH`, `AUDIT_CHROME`. Семантические триггеры и маршруты проверяются независимым агентом по этому файлу и актуальному SKILL.md; прохождение unit-тестов не доказывает прохождение этих сценариев.

## Регрессионный контракт расширения 14.10.2026

Исходные 11 тестов сохранены. Дополнительные тесты используют отдельные изолированные страницы локального HTTP-сервера: доступ разрешён только через явный `allow_local=True` / `--allow-local`, production-сайты не запрашиваются. Браузерные тесты требуют реальный Chrome и исполняют сценарии, а не только проверяют форму JSON.

Контрпримеры проверяются раздельно: SVG не меняет `head/title`; fallback не превращает меню в основной текст; пустая выборка не получает положительный вердикт; sitemap не задаёт навигационную глубину; точная пара не попадает в близкие дубли; HTTP 200 не доказывает наличие якоря; JSON-LD-кандидат не является санкцией; повторная gzip-проба и 304 не перезаписывают исходный HTML. Дополнительные сетевые пробы сохраняют прежние robots и query-гейты.

Кратчайший путь проверяется на графе с двумя альтернативами и изолированным sitemap-адресом. Лимит изображений проверяется по фактическим запросам сервера и числам «обнаружено / измерено». Браузерный отказ iframe проверяется отдельно от отказа главного перехода; целевой query не должен достигнуть сервера. Инструментальная серия покрытия кода не формирует чистые скоростные медианы. Вложенные неисполненные диапазоны кода вычитаются из родительского диапазона, а повторения не удваивают итог.

Пропуск браузерных тестов означает отсутствие проверки браузерного слоя в данном запуске. Число пройденных тестов не доказывает полноту аудита конкретного сайта; полнота остаётся в его физическом coverage-реестре и ограничена указанным охватом. Фактический результат расширенного набора добавляется только после интеграционного запуска.
