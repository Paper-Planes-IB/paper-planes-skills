# concept-deep-dive

Назначение: глубокий разбор концепции с опорой на vault: собрать определения, примеры, связи, и сформировать обогащённую заметку.

v0: создаёт scaffold в `Vault/30-база-знаний/технические-карточки/Concepts/<Концепт>.md`.

Запуск:

```bash
python3 scripts/concept_deep_dive_scaffold.py --concept "Концепт"
```
