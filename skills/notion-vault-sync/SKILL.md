# notion-vault-sync

Назначение: синхронизация заметок/протоколов между Notion и Vault.

Статус: v0 заглушка. Ранее в cloud это делалось через Notion MCP и отдельные cron'ы.
В текущем контуре Notion-sync отключён и вынесен в отдельную задачу (нужен выбор канала: прямой API или MCP с явным акцептом).

Что делает сейчас:
- создаёт чеклист синхронизации в `Vault/60-отчёты/notion-sync/<ДД-ММ-ГГГГ>.md`.

Запуск:

```bash
python3 scripts/notion_sync_checklist.py
```
