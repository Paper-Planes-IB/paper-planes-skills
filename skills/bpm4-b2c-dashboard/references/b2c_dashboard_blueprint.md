# Blueprint обезличенного B2C-дашборда

## Навигация

1. Обзор бизнеса.
2. Выручка и формула прибыли.
3. Клиентская база.
4. Повторные покупки.
5. RFM и кластеры.
6. Когорты.
7. Товары, категории, бренды.
8. Каналы и точки.
9. Качество данных.

## 1. Обзор бизнеса

Карточки:

- выручка net;
- валовая прибыль;
- маржинальность;
- количество чеков;
- количество уникальных клиентов;
- доля повторных клиентов;
- средний чек;
- средняя частота покупок;
- доля неопознанных продаж;
- доля возвратов.

Графики:

- выручка по месяцам;
- клиенты: новые и повторные;
- чеки по месяцам;
- валовая прибыль по месяцам.

## 2. Выручка и формула прибыли

Логика:

`Выручка = клиенты × частота покупок × средний чек`

`Средний чек = среднее количество позиций × средняя цена позиции`

`Валовая прибыль = net_revenue - cost_amount`

Графики:

- waterfall изменения выручки;
- вклад клиентов, частоты и среднего чека в изменение;
- прибыль по категориям;
- скидки и возвраты по периодам.

## 3. Клиентская база

Блоки:

- база покупателей: все, активные, новые, повторные, спящие, потерянные;
- динамика активной базы;
- структура по регионам, каналам, точкам;
- доля покупателей со стабильным ID.

## 4. Повторные покупки

Обязательные графики:

- доля клиентов с 2+ покупками;
- распределение количества покупок на клиента;
- среднее число дней между 1-й и 2-й покупкой;
- повтор по категориям первой покупки;
- повтор по каналам привлечения;
- динамика repeat rate по месяцам.

## 5. RFM и кластеры

Обязательные графики:

- таблица RFM-сегментов;
- RFM-матрица;
- выручка и клиенты по сегментам;
- распределение Recency, Frequency, Monetary;
- миграция сегментов между периодами;
- кластеры клиентов по RFM и поведению.

## 6. Когорты

Обязательные графики:

- retention matrix по месяцу первой покупки;
- выручка когорт по месяцам жизни;
- повторная покупка в 30, 60, 90 дней;
- LTV когорт, если период наблюдения достаточный.

## 7. Товары, категории, бренды

Графики:

- топ категорий по выручке, прибыли, чекам и штукам;
- категории первой покупки и их повтор;
- бренды или товарные группы по маржинальности;
- cross-sell: какие категории покупаются вместе;
- товары, растящие повторную покупку.

## 8. Каналы и точки

Графики:

- выручка и прибыль по каналам;
- новые и повторные клиенты по каналам;
- средний чек и частота по точкам;
- карта точек, если есть география;
- качество идентификации клиента по каналам.

## 9. Качество данных

Проверки:

- доля чеков без клиента;
- дубли `order_id`;
- отрицательные и нулевые чеки;
- доля возвратов;
- расхождение с управленческим итогом;
- партнёры и B2B, исключённые из B2C-слоя;
- пропуски по категориям, брендам, точкам.
