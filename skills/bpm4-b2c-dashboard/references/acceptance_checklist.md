# Чеклист приёмки B2C-дашборда

## 1. Данные

- [ ] Загружены `orders`, `order_items`, `customers`, `stores`.
- [ ] Есть стабильный `customer_id_hash`.
- [ ] Нет ФИО, телефонов, email и точных адресов.
- [ ] Есть флаги внутренних, тестовых, партнёрских и B2B-операций.
- [ ] Возвраты и скидки присутствуют отдельными полями.
- [ ] Доли неопознанных клиентов посчитаны отдельно.

## 2. Сверки

- [ ] Выручка сходится с источником.
- [ ] Количество чеков сходится с источником.
- [ ] Количество строк чека сходится с источником.
- [ ] Скидки сходятся с источником.
- [ ] Возвраты сходятся с источником.
- [ ] Валовая прибыль сходится с источником или явно помечена как недоступная.
- [ ] Расхождения описаны в отдельной таблице.

## 3. B2C-слой

- [ ] Партнёры выделены в `partner_registry`.
- [ ] Партнёры исключены из B2C-RFM.
- [ ] Сотрудники и внутренние продажи исключены.
- [ ] Тестовые чеки исключены.
- [ ] Корпоративные закупки не смешаны с конечными покупателями.

## 4. Повторные покупки

- [ ] Есть доля клиентов с 2+ покупками.
- [ ] Есть распределение покупок на клиента.
- [ ] Есть время до второй покупки.
- [ ] Есть repeat по категории первой покупки.
- [ ] Есть repeat по каналу привлечения.
- [ ] Клиенты без ID исключены из repeat-метрик.

## 5. RFM и кластеры

- [ ] RFM построен по конечным покупателям.
- [ ] Окно RFM зафиксировано.
- [ ] Пороги R/F/M описаны.
- [ ] Сегменты названы бизнес-языком.
- [ ] Есть таблица сегментов с клиентами, выручкой и частотой.
- [ ] Кластеризация запущена только при достаточном объёме данных.
- [ ] Кластеры интерпретированы и связаны с действиями.

## 6. Когорты

- [ ] Когорта задаётся месяцем первой покупки.
- [ ] Есть retention matrix.
- [ ] Есть повтор в 30/60/90 дней.
- [ ] Есть выручка когорт по месяцам жизни.

## 7. Витрины

- [ ] Обзор бизнеса собран.
- [ ] Формула прибыли собрана.
- [ ] Клиентская база собрана.
- [ ] Повторные покупки собраны.
- [ ] RFM и кластеры собраны.
- [ ] Когорты собраны.
- [ ] Категории, бренды и товары собраны.
- [ ] Каналы и точки собраны.
- [ ] Качество данных вынесено отдельным блоком.
