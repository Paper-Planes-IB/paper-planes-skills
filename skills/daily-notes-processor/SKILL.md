# daily-notes-processor

Назначение: пост-обработка Daily Note (proposal-only): собрать кандидаты решений/хвосты и вынести в отдельный отчёт, без переписывания Daily Note.

Артефакт:
- `Vault/60-отчёты/daily-notes-processor/<ДД-ММ-ГГГГ>.md`

Запуск:

```bash
python3 scripts/daily_notes_processor.py
```
