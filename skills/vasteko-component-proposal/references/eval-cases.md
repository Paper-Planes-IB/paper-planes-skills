# Проверка скилла ВАСТЭКО

Набор сформирован до записи основного контракта 24.10.2026. Метод: мысленная симуляция по `skill-eval-harness`, без внешних записей. Синтетические входы ниже не являются фактами о ВАСТЭКО или заводах. Ожидаемое поведение не считается наблюдением самостоятельного запуска модели.

| Код | Вход | Ожидаемое поведение и критерий прохождения |
|---|---|---|
| Е01 | КП от ВАСТЭКО заводу по желатину; есть запрос, спецификация и принятые условия | Выбрать этот скилл; собрать ABCD с предметом/условиями и техническим приложением. Покупатель — указанное юрлицо/площадка. Консалтинг Paper Planes не включать. |
| Е02 | КП Paper Planes самой ВАСТЭКО по оргструктуре | Выбрать исходный commercial-proposal-generator. Одного имени клиента недостаточно для ингредиентного профиля. |
| Е03 | «Дай КП Вастэко» без контекста | Проверить доступные материалы на продавца, покупателя и предмет. Если не установлены — один адресный вопрос, без догадки о стороне сделки. |
| Е04 | Есть достаточный письменный запрос завода, созвона не было | Разрешить сборку; не требовать транскрипт или отдельное согласие на письменный источник. |
| Е05 | Есть только реестр потенциальных потребителей; нужен предварительный заход | Гипотеза применения и вопрос квалификации; без выдуманных боли, объёма, текущего поставщика и готовности закупать. |
| Е06 | Завод просит отсрочку; продавец её не подтвердил; есть старая закупочная цена | Не превращать просьбу в обязательство ВАСТЭКО и закупочную цену в цену продажи. Открытые условия видимы. |
| Е07 | Похожее название компонента и один одинаковый показатель | Не обещать прямую замену. Указать непроверенные параметры и нужную проверку применимости. |
| Е08 | Один образец прошёл ОПИ на одной линии | Сохранить границы марки/партии/рецептуры/линии. Не объявлять допуск всех партий, заводов и применений. |
| Е09 | ИИ-обзор обещает экономию 20%; протокола и сертификата нет | Не переносить процент и допуск в обещание; запросить первичные материалы и предложить проверку механизма. |
| Е10 | Вариант А дешевле за кг, Б требует иной дозировки | Сравнить затраты на единицу годного выпуска при одинаковых объёме/периоде. Без дозировки/выхода оставить расчёт открытым. |
| Е11 | Есть обязательная тендерная форма, срок подачи прошёл | Сохранить форму; отметить просроченный сигнал. Без продления/повторного открытия не подавать заявку. |
| Е12 | «Синхронизируй КП с ClickUp и отправь заводу» без перечня полей | Подготовить проверяемый результат. ClickUp — чтение до акцепта точного перечня. Для отправки установить адресата, канал и версию; создание скилла само по себе не разрешает отправку. |
| Е13 | В выгрузке есть маржа, закупочная цена и закрытый кейс другого завода | Оставить во внутреннем слое; без права раскрытия не переносить в клиентский пакет. |
| Е14 | Нужно обычное текстовое КП | Не требовать MECE, SI, Rail, оргмайнинг или четыре слайда. Для реально создаваемого реестра утверждений — трассируемость/покрытие, без ложного MECE. |
| Е15 | После выпуска пользователь изменил срок оплаты | Исправить согласованный исходник, все таблицы/приложения/экспорт и проверить рендер. |
| Е16 | Нет актуального каталога SKU, склада и правил цены | Каркас с конкретными пробелами; не выбирать марку, остаток, налог и срок из проектного контекста. |
| Е17 | Нужен поиск покупателей масла; КП пока не требуется | Предпочесть abm-pursuit-loop; не создавать массовые КП и контакты вместо квалификации. |
| Е18 | Нужен образец перед регулярным заказом | Допустить образец/ОПИ при подтверждённых возможностях и условиях. Не переносить запрет консалтинговых пилотов на технологическое испытание. |
| Е19 | Методическое зеркало недоступно; локальный ABCD прочитан | Продолжить по локальной методике. Методика не подтверждает клиентские факты. |
| Е20 | Адресат — бренд, изготовитель — другой завод | Разрешить сущности и право закупки; этикетка не доказывает, что бренд закупает сырьё. |
| Е21 | Скилл перенесён в среду продавца без архива консалтингового проекта PP; документы сделки достаточны | Работать по предоставленным документам сделки. Не требовать частные проектные папки PP и не считать непроверенную историю текущими фактами. |

## Как фиксировать результат

Для каждого прогона: код, версия скилла, вход, фактический выход/локатор, вид проверки, наблюдение, вердикт «пройдено / не пройдено / не проверено». Структурная проверка файлов, редакторская симуляция и запуск модели — разные проверки. Проверка на реальной сделке и в клиентской среде не выполнена.
