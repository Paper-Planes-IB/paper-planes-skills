# Контракт архива встреч Paper Planes

## Каноническая папка

Google Drive: `Shared drives/Paper Planes/4. Производство/Встречи`.

Известная ссылка на корень архива:
`https://drive.google.com/drive/folders/1zLtWxQvEdUgUj_hZzCBPqkESGTSydS1e`.

Локальный путь зависит от аккаунта Google Drive. Скрипт ищет его внутри `~/Library/CloudStorage/GoogleDrive-*/Shared drives/Paper Planes/4. Производство/Встречи` и продолжает работу только при одном совпадении.

## Структура

```text
Встречи/
├── account.json
├── folder-registry.json
├── manifest.json
├── errors.jsonl
├── _Неразобранное/
└── {Проект}/
    └── YYYY-MM-DD__HH-MM__Название__meeting-id.md
```

Не создавать дополнительные уровни годов и месяцев: проектная папка должна сразу показывать хронологию встреч.

## Проектный реестр

Источником названий служит `list_meeting_folders`. Исключить папку `Проекты`, поскольку она агрегирует вложенные проекты. Остальные папки создать аддитивно. Заменить `/` и `:` на ` — `, убрать пробелы по краям. Одинаковые нормализованные названия объединить, сохранив все Granola folder ID в `folder-registry.json`.

Если встреча входит в несколько папок:

1. исключить агрегатор `Проекты`;
2. объединить дубли одинакового нормализованного названия;
3. выбрать папку с наименьшим положительным `note_count` как наиболее узкую;
4. при равенстве выбрать название по алфавиту и записать конфликт в manifest;
5. если проект подтвердить нельзя, использовать `_Неразобранное`.

## Формат Markdown

```markdown
---
meeting_id: "UUID"
title: "Название"
date: "2026-08-10T16:00:00+03:00"
project: "Агроэко"
granola_folder_ids:
  - "UUID"
source: "https://notes.granola.ai/t/..."
exported_at: "ISO-8601"
---

# Название встречи

## Транскрипт

Me: ...

Them: ...
```

Если Granola не вернула source URL, оставить пустую строку. URL нельзя конструировать по ID.

## Идемпотентность

- `manifest.json` является реестром обработанных meeting ID.
- Существующий непустой файл не изменять.
- При наличии записи в manifest и отсутствии файла выгрузить встречу повторно.
- Обновлять manifest через временный файл и атомарную замену.
- Ошибка одной встречи не останавливает пакет.
