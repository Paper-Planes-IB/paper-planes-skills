# Paper Planes Methodology Router

Use this file as routing guidance only. Canonical methodology detail lives in the Paper Planes Frappe LMS Wiki: `https://lms.paper-planes.ru/knowledge/glavnaya`.

## Selection Rules

| User intent | Primary models | Use in artifact | Frappe check |
|---|---|---|---|
| Executive argument, analytical note, storyline, management presentation | SCQA, Pyramid Principle, storyline-storyboard, action titles | Overall logic, slide sequence, executive summary | Check SCQA/storyline/action-title guidance if the output is client-facing or reusable |
| Segmentation, categories, tables, Mermaid diagrams, hierarchies | MECE, issue tree, hypothesis tree, taxonomy | Rows, columns, branches, swimlanes, tree levels | Check MECE and tree guidance when categories affect recommendations |
| Commercial proposal, landing page, sales deck, offer page | ABCD, RDB, JTBD, value proposition canvas, messaging house | Offer structure, benefits, proof, reasons to believe, next step | Check commercial/proposal/positioning guidance before final wording |
| Customer path, service gaps, onboarding, support, retention | CJM, service blueprint, jobs map, touchpoint inventory, experience map | Journey stages, touchpoints, pains, handoffs, moments of truth | Check CJM/service guidance when journey structure drives decisions |
| Dashboard, KPI system, operating review, management metrics | Formula of Profit, KPI tree, metric hierarchy, North Star Metric, leading/lagging indicators, owner rhythm | Metrics, filters, owners, review cadence, alert logic | Check metrics/dashboard guidance before changing source logic |
| Economics, pricing, margin, monetization, channels | Unit economics, LTV, CAC, payback, contribution margin, pocket price waterfall, price corridor | Financial model, pricing logic, sensitivity, commercial terms | Check finance/economics guidance before publishing numbers |
| Growth, experiments, backlog, prioritization | ICE, RICE, impact/effort, hypothesis card, experiment design, assumptions log | Backlog, scoring, test design, acceptance criteria | Check experiment/prioritization guidance before scoring |
| Market, competitors, external opportunity | TAM/SAM/SOM/PAM, market map, competitor matrix, 5 forces, PESTEL, demand/supply fit | Market sizing, competitor comparison, opportunity logic | Check market methodology before using external estimates |
| Portfolio, roadmap, product launch, assortment | BCG, GE/McKinsey, Ansoff, product lifecycle, NPD funnel, stage-gate | Portfolio map, roadmap, launch gates, assortment decisions | Check product/portfolio guidance before recommendations |
| Process, implementation, operating model, roles | PDCA/PDSA, SIPOC, value stream map, RACI, RAPID, DACI, governance cadence | Process map, responsibility matrix, implementation plan | Check process/governance guidance before assigning owners |
| Risk, governance, project control | Risk matrix, dependency map, decision log, issue/risk/action/owner register | Project control table, risk section, decision history | Check governance guidance for client-facing control artifacts |

## Mandatory MECE Trigger

Use MECE whenever the task contains segmentation, categorization, table design, Mermaid diagramming, hierarchical structures, issue trees, hypothesis trees, market maps, KPI trees, role matrices, or artifact templates.

## Output Rule

For every selected model, state:

- why it applies;
- where it appears in the artifact;
- whether Frappe live verification is required;
- what remains provisional if Frappe cannot be checked.
