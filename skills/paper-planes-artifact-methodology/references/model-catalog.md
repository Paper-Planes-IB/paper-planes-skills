# Model Catalog

Use this catalog when the router table is too coarse. Canonical explanations still live in Frappe LMS Wiki.

## Argument And Storyline

| Model | Use when | Artifact role |
|---|---|---|
| SCQA | Need to move from context to complication, question, and answer | Storyline, executive summary, slide flow |
| Pyramid Principle | Need a top-down argument | Executive memo, presentation sections |
| Storyline-storyboard | Need to plan a deck or slidument | Slide sequence and evidence allocation |
| Action titles | Each page or slide must carry a conclusion | Slide/page headings |
| Evidence ledger | Claims need traceability | Source table, appendix, QA checklist |
| Claim ledger | Claims may be disputed or reused externally | Risk control for public/client claims |
| Source gap log | Some facts are missing or weak | Explicit open-source gaps |

## Structure And Diagnostics

| Model | Use when | Artifact role |
|---|---|---|
| MECE | Need categories, hierarchy, table, map, tree, Mermaid diagram | Structure quality gate |
| Issue tree | Need to decompose a problem | Diagnostic tree |
| Hypothesis tree | Need to test possible explanations | Hypothesis map and research plan |
| Problem map | Need to connect symptoms, causes, consequences | Diagnostic narrative |
| Ishikawa | Need root-cause categories | Cause diagram |
| 5 Whys | Need quick causal drill-down | Interview or workshop prompt |
| Assumptions log | Logic rests on unproven assumptions | Risk and validation table |

| Need-state segmentation | Need segments by problem and context | Positioning and offer logic |

| Competitor matrix | Need structured comparison | Competitor slide/table |
| 5 forces | Need industry pressure analysis | Market attractiveness |
| PESTEL | Need macro-environment scan | External risk/opportunity |
| Demand/supply fit | Need to compare market demand with offer strength | Commercial opportunity logic |
