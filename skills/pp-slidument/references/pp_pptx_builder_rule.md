# Правило: генерация PPTX для Paper Planes — НЕ через consulting-slides-creator

Зафиксировано Натальей 2026-06-04 на проекте Элевел.

## Суть правила

Скилл `consulting-slides-creator` (38 layout'ов через `src/generator.py`) **НЕ подходит** — Наталья назвала результат «лютое говно»: слайды получаются голые, без визуальной плотности и стилистики, к которой мы пришли в HTML-материалах Элевела (paper-фон, цветные акценты, чипы, плашки, схемы).

**Как надо:** сначала верстаем слайд/материал в HTML в фирменной light-стилистике Элевела (одобрена Натальей), потом превращаем HTML в PPTX **двумя способами на выбор**:

1. **Растровый (быстро, 1:1)** — рендер HTML в PNG через Chrome headless `--screenshot --window-size=1280,720 --force-device-scale-factor=2`, вставка картинкой во весь слайд 16:9 через python-pptx. Текст не редактируется. Для показа/согласования.
2. **Редактируемый (нативные элементы)** — переписываем слайд на python-pptx руками: фон-прямоугольник PAPER, нативные shapes/textboxes/таблицы, цветные плашки и акцент-бары слева, чипы с бейджами. Это то, что Наталья одобрила («как надо ты сделал уже с прошлым html элевле»). По умолчанию — этот способ, если просят «редактируемый».

## Эталоны кода (рабочие builder'ы)

- Полная дека 19 слайдов: подход из `/tmp/elevel_pptx_builder.py` (фон PAPER, header с тегом ЭЛЕВЕЛ + section + дата + линия, action title 22-23pt, карточки с accent-баром слева 0.06-0.07", footer с источником italic + номер моно). FONT = "PT Sans" (надёжен для кириллицы в PowerPoint, Inter Tight может не подставиться).
- Один слайд-схема: `/tmp/elevel_block0_slide.html` (HTML) → editable PPTX (`Элевел_Блок0_рамка_оценки_editable.pptx`, 52 нативных shape).

## Размер слайда
16:9 = `prs.slide_width=Inches(13.333)`, `slide_height=Inches(7.5)`. Поля ~0.55". Layout пустой `prs.slide_layouts[6]`.

## Helper'ы (минимум)
- `rect(x,y,w,h,fill,line)` — прямоугольник, `shadow.inherit=False`, line.fill.background() если без рамки.
- `txt(shape,text,size,bold,color,font,align)` — текст в shape, word_wrap, маленькие margin'ы.
- accent-бар = узкий rect поверх левого края карточки.
- чип = белый rect + цветной бейдж-rect с моно-номером + textbox с подписью.

## Лого как глобальный слой

Лого Paper Planes добавляется через общий HTML-шаблон или генератор деки. Нельзя чинить его вручную на отдельных слайдах: при пересборке позиция и размер должны остаться одинаковыми по всей деке.

Рекомендуемый слот: нижний левый угол, единый отступ от края. Если в конкретном проекте используется другой слот, он задаётся один раз в генераторе.

Проверка:
- в HTML-версии лого есть на каждом слайде, где оно предусмотрено;
- после HTML→PPTX лого попало и в raster, и в editable-версию;
- замена логотипа проходит через одну переменную / asset path / helper, а не через копирование по слайдам;
- после публикации PP Pages страница проверена в браузере.

Для Figma-процесса: объект с лого лучше называть `лого` или `logo`, чтобы плагин нумерации мог найти его и клонировать на слайды.
