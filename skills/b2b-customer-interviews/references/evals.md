# Регрессионные случаи

Режим: reasoning-only. Проверка инструкций выполнена при создании 2026-11-09; отдельный агент и новое реальное интервью не запускались.

| Случай | Запрос / данные | Требуемое поведение | Ошибка |
|---|---|---|---|
| Good trigger | Гайд интервью покупателей B2B SaaS | Родитель для источников, этот скилл для MEDDPICC и статусов | Общий опрос удовлетворённости |
| Adjacent | Интервью сотрудников об оргструктуре | Организационный режим родителя | Покупательские роли вместо управления |
| Ambiguous | «Сделай интервью», проект не указан | Найти контекст; спросить, если аудитория остаётся неясной | Самостоятельно объявить B2B |
| Reference | Пользователь просит исходные формулировки | Прочитать точный источник, сохранить пригодное | Выдать собственный пересказ за оригинал |
| Missing reference | Названный гайд недоступен | Сообщить источник и ограничение по текущему gate | Сочинить аналог и продолжить как по референсу |
| Multi-product | Поставщик продаёт несколько продуктов | Вопросы о поставщике, общая развилка доппродуктов | Весь гайд только о главном продукте |
| Known data | В CRM видны продукты и масштаб | Предзаполнить, спрашивать о роли и причинах | Просить перечислить инструменты |
| No awareness | Неклиент не знает продукт | Задача и реальный выбор категории | «Почему отказались?» и «как оценили цену?» |
| No trial | Знает продукт, теста не было | Причина отсутствия рассмотрения | Результаты несуществовавшего теста |
| Evidence | Бесплатный тест, оплаты нет | Отдельно тест, итог и решение об оплате | Считать доказанной готовность платить |
| Proxy | B2B-покупатель говорит о конечных пользователях | Запросы, фактически наблюдавшиеся действия | Прогноз мотивов от имени пользователей |
| Negative hypothesis | Есть гипотеза экономии | Ожидаемые выгоды открытым вопросом | «Что перевесило экономию?» |
| Base preservation | Встроить 15 гипотез | Сохранить основные вопросы, добавить условные уточнения | Полная пересборка и рост обязательного маршрута |
| Standard headings | Просьба стандартизировать | Восемь терминов MEDDPICC | Авторские замены «бюджет и полномочия» и т. п. |
| Missing value | Сборка финального гайда | Вопрос о том, чего клиент не получает, перед открытым завершением | Только «что мы не обсудили» |
| Bilingual | Обновить RU/EN Doc | Условия, смысл, номера совпадают; readback | Обновить только RU |
| Externalization | Подготовить и записать гайд | Сохранить в разрешённом документе | Отправить респондентам без поручения |
| Canon separation | Прикреплены гипотезы одного клиента | Проверять в проекте; в методе оставить механизм | Продуктовые гипотезы как общий канон |

Результат самостоятельного walkthrough: инструкции покрывают все 18 случаев. Это проверка наличия решений и непротиворечивости, а не доказательство поведения модели в независимом запуске.
