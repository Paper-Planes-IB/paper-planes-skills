# Скиллы Paper Planes

Закрытый канонический репозиторий скиллов Paper Planes.

## Поток обновления

1. Илья публикует рабочие пакеты в `CLAUDE/Codex/skills` на Google Drive.
2. Локальная автоматизация каждые шесть часов забирает полный снимок по постоянному идентификатору папки.
3. Проверка сохраняет структуру пакетов, считает контрольные суммы и блокирует публикацию при ошибках или признаках секретов.
4. GitHub хранит историю изменений.
5. Проверенные данные публикуются в существующий большой реестр скиллов Frappe Wiki.

Исчезнувшие из источника пакеты сохраняются со статусом `legacy`. Удаление выполняется только после подтверждения Натальи.

## Ручной запуск

```bash
./scripts/run_sync_and_publish.sh
```
